# Unity-game-portfolio
Unityを使用して個人制作した3Dゲームです。

## ゲームタイトル

「自己中な友達のお願いを聞くゲーム」

## ゲーム概要

わがままで手が付けられないfriend。
そんなfriendから出されるクエストをプレイヤーがクリアしてことで、
ステージ内のイベントを進める3Dゲームです。

## 自分が制作した部分

- ゲームの企画・仕様設計
- シナリオ・会話内容
- プレイヤーの移動処理
- NPCとの会話システム
- アイテム取得処理
- イベント・クエスト進行
- オートセーブ機能
- カメラ制御
- ステージおよびレベルデザイン
- タイトル画面、操作説明、エンドロール、ゲームシーン、会話パネルなどのUI制作

## 使用技術

- Unity
- C#
- ProBuilder/Terrain
- Animator/Blend Tree
- AudioSource
- PlayerPrefs/JSONシリアライズ
